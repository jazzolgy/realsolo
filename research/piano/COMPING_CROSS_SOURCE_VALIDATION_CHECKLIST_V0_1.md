# Piano Comping Cross-Source Validation Checklist v0.1

Purpose: prevent McNeely-specific examples and RealSolo implementation heuristics from
silently becoming universal jazz-piano rules.

## Evidence labels

- SOURCE-DERIVED: explicitly supported by the source.
- CROSS-SOURCE-CONFIRMED: supported by two or more independent sources.
- STYLE/ERA-CONDITIONAL: supported, but only under a documented style/era/context.
- EXPERT-EDITORIAL: accepted provisionally through domain-expert judgment.
- DESIGN-INFERENCE: useful RealSolo abstraction not stated by a source.
- OPEN: unresolved or contradictory evidence.

## A. Interaction / role grammar

Check whether the source supports or contradicts:

- silence / lay-out as a first-class musical action
- support vs answer vs punctuation vs fill vs build vs release distinctions
- phrase-space sensitivity
- soloist-led vs reciprocal dialogue
- drummer interaction
- bass interaction
- role changes over a chorus / section
- whether role labels are pedagogical/source terminology or only RealSolo abstractions

Questions:

1. Does the source explicitly tell the pianist when not to play?
2. Does it describe response/call-and-response or only accompaniment support?
3. Does it distinguish phrase-end fills from mid-phrase punctuation?
4. Does it treat rhythm-section interaction as reciprocal or primarily pianist-following?

## B. Rhythmic placement

Validate:

- on-beat
- anticipation
- offbeat punctuation
- delayed answer
- sustained support
- repeated groove identity vs literal fixed pattern
- rhythmic activity change across phrase/chorus
- fast tempo: event rate vs larger half-time internal pulse

Questions:

1. Are placement choices tied to harmony, phrase, drummer, style, or all of them?
2. Is anticipation a generic comping device or style-specific?
3. Does the source teach rhythmic motifs as reusable identities?
4. When is repetition desirable?

## C. Voicing-family competition

Validate:

- shell / guide-tone
- rootless
- tertian
- quartal
- inverted quartal
- mixed / combination
- octave structures
- upper structures
- clusters
- open/spread structures
- block/harmonized-line structures

For every family record:

- harmonic context
- register
- bass presence
- top-note constraints
- typical density
- style/era association, if the source states one
- whether the family is prescriptive, optional, or merely demonstrated

Do not infer a style/era label unless the source supports it.

## D. Register / density / expression

Validate:

- register separation from soloist
- register separation from bass
- register changes during bass solo
- density increase/decrease across solo development
- dynamics / weight
- articulation
- pedal / sustain
- percussive piano treatment
- whether energy growth means louder, denser, wider, higher, more active, or some
  combination rather than a single scalar

## E. Variation versus continuity

Validate RealSolo hypotheses:

- exact repetition may be undesirable
- partial continuity can be musical
- groove identity can justify repeated rhythm
- family/role continuity can function motifically
- variation may occur in timing, register, dynamics, touch, voicing, or density
- silence may repeat intentionally and should not be treated like repeated notes

Questions:

1. Does the source actively recommend varying material?
2. Does it also recommend maintaining ostinato/groove/motif identity?
3. Which dimensions are varied while others remain stable?

## F. Ensemble-response intelligence

Check whether the source provides evidence for:

- drummer echo / accent alignment
- soloist phrase extension after comping
- response windows after phrase end
- ensemble density change after piano gesture
- bass response
- harmonic response
- attribution/causality caution

Important:

A source showing temporal succession does not by itself prove that one player caused
another player's response.

## G. Interaction episodes

Current RealSolo experimental types:

- OPEN_DIALOGUE
- SOLOIST_LEAD
- DENSITY_SHIFT
- UNCLASSIFIED

For each source, ask:

1. Does it describe multi-turn interaction rather than isolated reactions?
2. Does a dialogue persist over several gestures?
3. What marks the end of the interaction?
4. Are there other recurring episode shapes not represented above?
5. Are the current labels too coarse or stylistically biased?

Do not promote these labels to Shared Core until cross-instrument/source evidence exists.

## H. Style / era evidence for future presets

Do **not** assume Old / Modern / New.

Instead collect source-supported dimensions such as:

- functional vs modal/non-functional tendency
- tertian vs quartal/cluster tendency
- compact vs open register
- explicit vs ambiguous harmony
- low vs high rhythmic displacement
- sparse vs dense accompaniment
- groove-preserving vs highly variable rhythm
- degree of interaction with soloist/drums/bass

Only after enough evidence exists should user-facing presets be named.

## I. Promotion rule

A piano heuristic may move toward stable grammar when one of these is true:

1. at least two independent high-quality sources support it in similar context;
2. one strong source plus repeated expert validation supports it;
3. controlled preference tests consistently favor it;
4. the rule is clearly context-conditional and the condition is represented explicitly.

If sources disagree, preserve alternate tendencies rather than averaging away the
difference.

## J. What to request from the next source

Best next source types:

1. a book focused specifically on interactive jazz comping rather than harmony alone;
2. a voicing book with strong contextual guidance, not only chord-shape catalogs;
3. a contemporary/post-bop comping source useful for checking whether the current
   McNeely-derived interaction and modal assumptions generalize.

A source dominated by static voicing diagrams is useful for voicing taxonomy, but not
sufficient to validate interaction episodes or response logic.
