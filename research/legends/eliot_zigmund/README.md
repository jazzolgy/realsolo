# Eliot Zigmund Legend Research

This directory owns source-grounded research about Eliot Zigmund as a legend
profile. Instrument players may consume promoted vocabulary through the generic
Legend interfaces; `players/drums/` does not own this research.

Current evidence set starts with the Bill Evans recording of `Without a Song`
from the 1977 `You Must Believe in Spring` sessions.

The first promoted vocabulary items are deliberately **abstracted rhythmic
cells**, not literal phrase transcriptions. They come from the documented drum
solo region around 6:52 and are stored with moderate confidence because the
source is a mixed trio recording rather than an isolated drum stem.

Research flow:

SOURCE
→ OBSERVATION
→ VOCABULARY EXTRACTION
→ ABSTRACTION
→ CONDITIONAL RUNTIME USE
