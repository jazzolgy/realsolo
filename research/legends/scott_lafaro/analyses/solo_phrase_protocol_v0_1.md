# Scott LaFaro Solo Phrase Protocol v0.1

## Goal

Convert verified LaFaro recordings into causal solo intelligence rather than
style adjectives.

The unit of analysis is:

**one committed phrase idea -> its development -> ensemble response -> next idea**

## Shared Solo Grammar mapping

Annotate every phrase event with zero or more:
- STATE
- REPEAT
- VARY
- FRAGMENT
- EXTEND
- CONTRACT
- INVERT
- SEQUENCE
- DISPLACE
- AUGMENT
- DIMINISH
- CHANGE_REGISTER
- ADD_SPACE
- INTERNAL_REST
- CONTRAST
- RECAP
- RESOLVE
- TARGET_NEXT_HARMONY
- ANSWER

These operations are shared grammar, not LaFaro-owned concepts.

## Bass-specific evidence dimensions

For each phrase:
1. interval schema
2. rhythm schema
3. contour
4. register start / peak / landing
5. accent shape
6. note-body profile
7. harmonic target behavior
8. tension-release shape
9. interaction function
10. phrase entrance / ending
11. repetition identity
12. physical feasibility / articulation

## Promotion gate

A tendency may enter Scott LaFaro LegendProfile only if:
- source identity/personnel are verified;
- observation is phrase-level and context-tagged;
- it recurs in more than one independent window, or is retained only as
  vocabulary evidence rather than a general tendency;
- exact copyrighted phrase content is not required by the runtime prior.

Literal or transposed vocabulary may be retained privately with provenance,
but public/runtime representations should prefer abstract/hybrid use unless
rights and similarity policy permit otherwise.
