# Scott LaFaro Intelligence

Canonical research home for Scott LaFaro in RealSolo.

## Status

Evidence-gated. No runtime tendency is promoted from reputation, general jazz
knowledge, or model memory alone.

Pipeline:

SOURCE
-> VERIFIED PERSONNEL / TAKE IDENTITY
-> PHRASE-LEVEL OBSERVATION
-> SCORE / FORM ALIGNMENT
-> MOTIF / RHYTHM / REGISTER / INTERACTION ABSTRACTION
-> VOCABULARY + CONDITIONAL PRIORS
-> BASS SOLO RUNTIME

Scott LaFaro does not own generic solo methodology. Motif development,
variation, fragmentation, sequence, displacement, register change, tension
extension, space, recap and resolution remain Shared Solo Grammar.

The LaFaro layer stores evidence for **when and how** those shared operations
are used by LaFaro, together with source and context.

Raw copyrighted audio is never committed.
