# Scott LaFaro Audio Observations

Use only personnel/master-verified sources.

Observation units are phrase windows, not whole-track averages.

For each window record:
- source / timestamp / chorus / score-form position
- foreground/background role
- motif identity and transformation
- rhythm cell and displacement
- register trajectory
- interval-leap behavior
- harmonic targeting vs tension prolongation
- note body / accent / articulation
- space / interruption / response
- piano and drums context
- confidence and recurrence count

Do not infer exact notes from mixed audio when uncertain.
Do not promote mixed-audio low-band measurements as bass-specific facts.
