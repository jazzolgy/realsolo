# Bill Evans Cross-Version Listening Matrix v0.1

## Purpose

Identify alternate performances on YouTube/public web that allow RealSolo to
separate:

1. tune-specific behavior,
2. Bill Evans trio-level behavior,
3. bassist-specific behavior,
4. drummer/era/context effects.

Important: current web tooling can verify YouTube/public-page metadata and
personnel, but cannot directly audition/extract the external YouTube audio
stream. Therefore all external versions below are marked **audio_pending** until
their audio becomes available inside the project.

The owner-supplied compilation remains the only directly analyzable audio source
in this workspace.

## Research strategy after external audio acquisition

For each version pair:

1. Align score form.
2. Select the same 4–8 bar harmonic location.
3. Measure/annotate:
   - root occupancy
   - chord-tone occupancy
   - chromatic approach
   - scalar motion
   - register center/span/slope
   - note-body duration
   - attack/accent distribution
   - offbeat/subdivision activity
   - productive repetition
   - piano RH/LH density
   - drum setup/fill state
4. Compare within tune across bassists.
5. Compare within bassist across tunes.
6. Promote only repeated effects.
