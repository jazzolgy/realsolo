# Audio observations

Create track-level and passage-level observations here.

Do not infer tune identity from general knowledge alone. Resolve tune identity
against the project audio and master_index/scorebook evidence when possible.

Each observation should preserve:
- source_id
- track / timestamp
- tune_id when verified
- scorebook / page when verified
- form position
- current foreground player
- Piano RH role
- Piano LH role
- Bass role
- Drums role
- ensemble density
- interaction event
- confidence
- provenance
