# Structural alignment

This directory is the canonical sidecar for musical-position migration.

Rules:
- preserve raw timestamps as provenance;
- compare/learn using structural musical coordinates;
- do not infer missing bars merely from elapsed percentage;
- rubato intros, interludes, vamps, tags, codas and outros may remain outside
  the recurring core form until their navigation is verified;
- an unaligned observation remains useful for navigation but cannot be promoted
  directly into Legend runtime policy.
