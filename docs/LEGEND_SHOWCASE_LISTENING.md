# Legend Showcase Listening Mode

This mode exists for one purpose: hear the strongest **currently promoted**
Legend Intelligence in the audible quartet path without the conservative
production selector damping it.

## Browser

Choose:

```text
Legend Showcase — full promoted legends
```

The mode still uses:

- Autumn Leaves / G minor
- Jazz Jam Session convention
- SWING
- ELASTIC
- HUMAN_DRIFT off
- same-snapshot / ONE-EVENT causal runtime

## Current promoted Legend content

### Charlie Parker → Sax

Showcase weight: **1.0**

The Sax path receives the full promoted Parker profile stack, not only the
LINEAR_CONNECTION slice:

- online contextual profile
- symbolic motion profile
- phrase/space profile
- all promoted Legend domains exposed to current-event matching

A tendency still influences a note only when the current candidate carries a
compatible musical feature/tag. Showcase mode does not force every tendency
onto every note.

### Scott LaFaro → Bass

Showcase weight: **1.0**

The full promoted LaFaro profile is made available through the existing Bass
Legend contract. The current LaFaro tendencies are primarily solo/development
evidence; they are not falsely reinterpreted as generic walking-bass rules.

### Bill Evans → Piano

The Bill Evans runtime profile is currently an evidence-gated scaffold with
zero promoted tendencies. Therefore Showcase mode cannot truthfully make a Bill
Evans prior audible yet.

The research files remain valuable evidence, but this mode does not convert
unpromoted research observations into runtime style claims merely to make the
performance sound more "Bill Evans-like."

### Vocabulary

The Parker / Bill Evans / LaFaro VocabularyIndex providers are connected but
their current item collections are empty. Showcase mode does not fabricate lick
memory.

## Why this mode is separate

Production/default jazz should not automatically become a named-musician
imitation. Legend Showcase deliberately removes that conservative selection for
listening/research evaluation while keeping the normal mode intact.
