# Shared Structural Harmony Alignment

Harmony is attached to the same musical coordinate used by every player.

Three evidence classes must remain distinct:

1. EXPECTED
   - licensed/shared chord chart (for example iRealB Standard 100)
   - visually verified scorebook/lead sheet

2. OBSERVED
   - harmony actually heard/transcribed in the recording
   - bass note, voicing, substitution, pedal, reharmonization, omission

3. INFERRED
   - analytical interpretation such as ii-V, dominant approach, tonicization,
     modal function or cadence class

Expected harmony must never overwrite observed performance harmony.

Canonical comparison:

song / section / form_bar / beat
+ expected harmony
+ observed harmony
+ inferred function
+ player/ensemble action

This permits questions such as:
- Does Bill Evans substitute at the same form bar on later choruses?
- Does Scott LaFaro anticipate the expected root or answer the observed voicing?
- Does Paul Motian mark a cadence even when the harmony is reharmonized?
