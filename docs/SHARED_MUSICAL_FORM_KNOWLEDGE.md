# Shared Musical Form Knowledge

This document is shared by every RealSolo player and research domain.

## Core principle

Musical time should be represented primarily as **musical position**, not elapsed
recording time.

Preferred evidence coordinate:

song
→ arrangement segment
→ core form
→ section
→ form bar
→ score bar / beat when available
→ chorus / recurrence index
→ performance phase
→ ensemble role

A source timestamp remains provenance and a way to return to the recording.

## Form is hierarchical

A performance may contain both a recurring core form and one-off or inserted
arrangement segments.

Examples of non-core segments:
- rubato intro
- written intro
- pickup
- interlude
- solo break
- vamp
- tag
- cadenza
- transition
- coda
- outro
- fermata
- metric/feel transition
- arranged extension or contraction

These must not be forced into a recurring form-bar grid unless their location is
verified.

## Jazz

Common recurring vehicles include:
- 12-bar blues
- 32-bar AABA
- 32-bar ABAC/AABC variants
- rhythm changes: 32-bar AABA
- waltz forms
- modal/circular forms
- asymmetric standards
- vamps and open solo loops

Jazz often repeats the same form for multiple choruses. Therefore one of the
highest-value research comparisons is:

same form bar
× different chorus
× different foreground owner

The system must never infer that all jazz forms are 12 or 32 bars.

## Popular music

Popular music is commonly sectional:
- intro
- verse
- pre-chorus
- chorus/refrain
- post-chorus
- bridge
- solo
- breakdown/interlude
- outro/coda

The best coordinate is often:
section identity + section instance + bar within section.

Some popular music still uses 12-bar blues, 32-bar song form, strophic form, or
a repeating harmonic loop. Genre must not determine form automatically.

## Classical music

Classical form is often hierarchical and functional:
- binary
- ternary
- rondo
- theme and variations
- sonata exposition/development/recapitulation
- sonata-rondo
- fugue/contrapuntal process
- through-composed structures

These should not be reduced to a small chorus loop. Local phrase/bar coordinates
may coexist with larger formal-function coordinates.

## Minimal form knowledge for performance

When a full score is unavailable, the minimum useful position can still be:

- core form length
- current form bar
- recurrence/chorus index
- current performance phase
- arrangement-segment state
- distance to next known boundary

This is often sufficient for a drummer to maintain form-aware time, restraint,
setup, release and re-entry.

Harmony, melody and exact score position improve the decision but are not
required for basic form-aware drumming.

## Shared learning rule

Unaligned acoustic features are navigation evidence only.

Promotion path:

audio feature/event
→ arrangement/form alignment
→ instrument/ensemble attribution
→ repeated-position comparison
→ vocabulary / tendency / shared grammar

The preferred experiment is not "what happens at 70% of the recording?" but
"what happens at bar 31 of this 32-bar form across five choruses?"
