# Realtime

## Ownership principle

> **Realtime does not decide the music. Portable Core and Players decide the performance intention; Realtime executes that intention as sound on the mobile device accurately and with low latency.**

Realtime owns low-latency execution, scheduling, audio/MIDI I/O, device integration, and performance output. Musical policy belongs to Portable Core and Players.

Low-latency live ensemble runtime: perception, state tracking, scheduling and performance output.
